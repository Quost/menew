# Menew name and logo

The Menew source code is free software under the [GNU General Public License v3](LICENSE). The **name “Menew”, the Menew icon and logo, and the website menew.web.app** are not covered by that license: they identify the official app made by Matheus Quost.

## You can

- Say that your project is based on Menew, or that it works with Menew (“a fork of Menew”, “built on Menew”).
- Use the name and icon to talk about Menew: articles, reviews, videos, tutorials, lists of apps.
- Build Menew from source for yourself, with the name and icon, as long as you don’t distribute it.

## Please don’t

- Distribute a modified version, a fork or a repackaged build under the name Menew or with the Menew icon. Give it another name and icon so nobody confuses it with the official app.
- Use the name or icon in a way that suggests the official project endorses or makes your product.
- Register domains, app names, accounts or trademarks that include “Menew” for a different product.

## Official downloads

The official app is published only on [GitHub Releases](https://github.com/Quost/menew/releases), through the Homebrew tap in this repository and on [menew.web.app](https://menew.web.app). Official builds are signed with the Developer ID of Matheus Quost (team 9527N6XKKW) and notarized by Apple.
