Menew vs Rectangle and Magnet: window snapping for Mac, built in

Rectangle is a free, open source window manager and Magnet is a paid one. Menew snaps windows with the same ⌃⌥ shortcuts as Rectangle and by dragging to the screen edges, as part of a menu bar app that also has a command palette, clipboard history and more.

Which one fits you

Choose Rectangle and Magnet if

  • You want sixths, fourths or very fine-grained snapping options.
  • You only need a window manager.

Menew is enough if

  • The common layouts are enough and you'd like them in the same app as your clipboard and launcher.
  • You want work profiles that reopen apps and put their windows back.
