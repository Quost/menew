Menew 用一个基于 Swift 的快速原生应用，取代多个付费菜单栏工具。采用 macOS 26 的 Liquid Glass 设计。按需使用：可在设置中关闭模块。

系统监视器

带实时图表的 CPU 和 GPU、内存压力与交换、磁盘空间和读写速度、电池健康与循环次数，以及最占资源的进程，一键即可退出。可选提醒，并可自定义菜单栏显示内容。

剪贴板历史

文本、链接、图片和文件。即时搜索、筛选、置顶和丰富预览。用 ⌘⇧V 打开。复制私密内容时，可暂停 15 分钟或 1 小时。

快捷操作

每个屏幕的亮度，包括外接显示器。麦克风或声音静音、隐藏程序坞、深色模式、带定时的保持唤醒、隐藏文件和桌面图标。还有取色器、截图到剪贴板、推出磁盘等。保持唤醒还可设置到某个时间，或在某个应用打开期间生效。

释放空间

几秒内清理缓存、日志和开发残留。深度扫描会找出旧下载和大文件，由你确认。

网络

实时下载和上传速度、本地和公网 IP，以及由 macOS 自带工具完成的真实测速。

笔记、文本片段和设备

支持 #标签 和 Markdown 清单的笔记、用触控 ID 打开的受保护笔记，以及 ⌘⇧V 中可复用的文本片段。

剪贴板历史

再也不会丢失复制过的内容。

在任何地方按下 ⌘⇧V，输入几个字母后回车，内容会直接粘贴到你正在使用的应用中。

  • 智能预览——十六进制颜色色块、链接、图片和文件图标。
  • 筛选与置顶——在文本、链接、图片和文件之间切换；常用内容保持在最上方。
  • 密码安全——忽略 1Password、钥匙串等标记为密码的内容。你还可以直接从列表中选择要忽略的应用。

快捷操作

那些你每次都要去搜索的设置。

显示隐藏文件、隐藏桌面、让 Mac 保持唤醒一小时，或从屏幕任意位置取色——无需打开终端。每个开关都会显示当前状态。

  • 显示器亮度 — 每个屏幕一个滑块，第三方显示器也可通过 DDC/CI 调节。
  • 麦克风静音 — 在任何应用中按 ⌃⌥⌘M，开会很方便。
  • 窗口管理 — 用 ⌃⌥ 快捷键或网格把窗口放到半屏、四角和三分之一处，还能移到另一个显示器。
  • 命令面板 — 按 ⌃⌥空格，查找任意应用、操作、窗口布局、片段或笔记。输入 “亮度 60” 或 “awake 2h”。
  • 工作配置 — 保存打开的应用和窗口布局，一键全部恢复：应用自动打开，窗口回到原位，并设置麦克风和保持唤醒。
  • 快速暂存架 — 拖动文件时晃动鼠标即可唤出暂存架。把文件、链接和文本放进去，再一次性全部拖出。原文件不会被移动。
  • 自动化 — 9 点启用工作配置，打开 Zoom 时静音麦克风，拔掉电源时调暗屏幕。简单的触发条件，无需脚本。
隐私

你的数据永远不会离开你的 Mac。

Menew 是开源的，所以你无需只听我们的一面之词。

没有遥测

应用不会发送任何关于你的信息：没有分析、没有追踪、没有账户。永远如此。

本地存储

历史记录和笔记保存在 ~/Library/Application Support/Menew。
