常见问题

常见问题

Menew 真的免费吗？

是的。Menew 免费开源，采用 GPLv3 许可证：没有广告、没有订阅、没有付费版。如果它对你有帮助，可以请作者喝杯咖啡，但应用中从不索要。

Menew 会收集我的数据吗？

不会。没有遥测、没有分析、无需账号。剪贴板历史和笔记都保存在你的 Mac 上。唯一的网络连接是检查更新、你的公网 IP、你发起的测速和你请求的汇率。AI 功能只使用 Apple 的本机模型。 仅在你开启时，Menew 还会向 Anthropic 查询你的 Claude 套餐限额。

它支持哪些 Mac？

macOS 14 Sonoma 或更高版本，支持 Apple 芯片和 Intel。AI 功能需要 macOS 26 或更高版本并打开 Apple 智能。

如何安装？

下载 DMG 并将 Menew 拖到“应用程序”，或使用 Homebrew：添加 quost/menew tap 后运行 brew install --cask menew。更新会自动推送。

安装安全吗？

Menew 使用 Apple 开发者 ID 签名并经过 Apple 公证，全部源代码在 GitHub 上公开。

可以关闭不用的功能吗？

可以。在“设置 → 模块”中关闭剪贴板、操作或笔记，它们会完全消失。关闭剪贴板后，Menew 甚至不会读取剪贴板。

Menew 是 Raycast、Maccy、Rectangle 和 iStat Menus 的免费替代品吗？

是的。Menew 把它们的核心功能集中在一个应用里：像 Raycast 和 Maccy 一样的命令面板和剪贴板历史，与 Rectangle 相同快捷键的窗口贴靠，以及像 iStat Menus 一样带传感器和历史记录的系统监控。这些应用在各自领域仍然更深入，比如 Raycast 的扩展商店。

AI 需要联网或账号吗？

不需要。Menew 只使用在 Mac 本机运行的 Apple 模型（Apple Intelligence），文字、截图和问题都不会离开你的 Mac。无需 API 密钥、账号或额外费用。

如果我的 Mac 没有 Apple Intelligence 怎么办？

其他功能完全照常。AI 功能会提示如何开启 Apple Intelligence，而不是直接出错；“Mac 变慢”诊断仍会列出问题；剪贴板智能搜索也无需它即可使用。

如何卸载 Menew？

从 Menew 菜单退出，然后把它从“应用程序”拖到废纸篓，或运行 brew uninstall --cask menew。历史记录和笔记保存在 ~/Library/Application Support/Menew，也可以一并删除。

Menew 会让 Mac 变慢或耗电吗？

Menew 是原生 Swift 应用，不是网页套壳，下载约 8 MB。它每 2 秒读取一次系统数据，较重的读取只在你查看时进行，屏幕使用时间等功能默认关闭。

Menew 支持哪些语言？

英语、葡萄牙语、德语、西班牙语和简体中文。默认跟随 macOS 语言，也可以在设置中更改。

Menew 能录制会议并写会议纪要吗？

可以。按 ⌃⌥⌘G（或在“现在”标签中点“录制”），选择 Mac 声音和麦克风、仅 Mac 声音或仅麦克风。Mac 会转写并区分你和其他人，Apple 的本机 AI 会写出摘要、决定和任务，任务可发送到“提醒事项”。不会有机器人加入通话，什么都不会上传，过短或空白的录音也不会生成编造的纪要。

Mac 上有免费、私密的 Granola 或 Otter 替代品吗？

Menew 的录音功能覆盖日常所需：转写、纪要和任务，用 Apple 的模型在你的 Mac 上完成，免费且无需账号。Granola 和 Otter 则更进一步，提供团队共享和云端集成。

之后怎么找回在屏幕上看到过的东西？

看到时按 ⌃⌥⌘K 存入“记忆”：Menew 保存图像、读取文字，并记下 App 和链接。之后用自己的话搜索或提问，比如“那个 Swift 图表库叫什么来着？”，本机 AI 会以保存的条目为来源作答。记忆条目也会出现在 Spotlight 中。也可以打开自动记忆：每张截图、会议纪要、笔记和每个编程代理会话的摘要都会自动保存在你的 Mac 上。

Menew 和 Linx Menew 有关系吗？

没有。Menew 是 Quost 开发的免费开源 Mac 菜单栏应用，发布在 github.com/Quost/menew。Linx Menew 是巴西一款与之无关的餐厅收银系统，只是名字相似。

Menew 不能做什么？

Menew 不会隐藏或重新排列其他应用的菜单栏图标（可以使用 Ice 或 Thaw），没有像 Raycast 那样的扩展商店（而是运行你自己的脚本），不在 Mac 之间或云端同步，也不会在菜单栏里放浏览器。若需要按核心的详细硬件传感器，Stats 和 iStat Menus 更深入，不过 Menew 也能显示芯片、SSD 和电池温度、风扇转速以及性能核与能效核。

Menew 能显示 Claude Code、Codex、Gemini 等编程智能体的用量和限额吗？

可以。“AI 智能体”部分读取 Claude Code、Codex、Gemini CLI、Cursor、Copilot CLI、Kiro、OpenCode、Droid、Qwen Code、Amp、OpenClaw、Kimi 和 Goose 本来就保存在 Mac 上的日志，按天、周或月显示最长 12 个月或全部历史的 token（由于 Claude Code 会在 30 天后删除日志，Menew 会保留一份很小的每日汇总），并按工具和应用（终端、桌面应用或 IDE）细分，还显示按 API 价格估算的费用、缓存节省以及用得最多的模型和项目。Codex 限额来自它自己的日志；Claude 的 5 小时和每周限额来自 Anthropic，因此是可选的。开启 hooks 后，智能体完成或等待你授权时，刘海处会提醒你。MCP 服务器让智能体可以搜索你的记忆、笔记和会议纪要。
