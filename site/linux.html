Coming to Linux

Menew for Linux

The free, open source menu bar app you use every day on the Mac — command palette, clipboard history, system monitor and local AI — coming to Linux, native and lightweight.

🛠 In development
⭐ Star on GitHub Menew for Mac →

What's planned

⌨️

Command palette

Open any app, action, snippet or note with a global shortcut. Math, conversions, timers and your own scripts — from the keyboard.

📋

Clipboard history

Every text, link and image you copy, searchable in one click. Password-safe by design; works on Wayland and X11.

📊

System monitor

CPU, memory, disk and network in the system tray. Reads /proc and /sys — no daemons, no root.

🤖

Local AI

Transcribe meetings offline with Whisper, summarize and rewrite text with a local model via Ollama or llama.cpp. No account, no cloud.

🎙️

Meeting minutes

Record your mic and system audio separately via PipeWire, transcribe offline and generate minutes with tasks — all on your machine.

📝

Notes and snippets

Quick notes with Markdown, reusable text snippets with abbreviations, and a search that understands what you mean.

Built with

🦀 Rust 🖼 GTK4 + Libadwaita 🔊 PipeWire 🗄 SQLite (FTS5) 🌊 Wayland + X11 🤫 whisper.cpp

Native Rust with GTK4 and Libadwaita: integrates with GNOME and KDE themes, respects dark/light mode, works on Wayland-first with an X11 fallback, and keeps memory usage around 25–40 MB. No Electron, no WebKitGTK, no web wrapper.
